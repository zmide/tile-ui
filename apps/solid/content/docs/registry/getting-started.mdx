The Solid registry is assembled from `packages/solid/src/registry` and published under `apps/solid/public/r`.

## Consumer setup

```json
{
	"registries": {
		"@tile-ui": "https://solid.tileui.zmorg.cn/r/{name}.json"
	}
}
```

## Install an item

```bash
pnpm dlx shadcn@latest add @tile-ui/button
```

Registry dependencies bring in shared core logic, styles, and Solid event helpers automatically.

## Optional themes

See [Theme resources](/docs/themes) for available themes and [the Kumo guide](/docs/themes/kumo) for its package and registry setup.

## Build flow

```bash
corepack pnpm registry:build:solid
```

## Current scope

The registry contains 71 items: 62 UI components spanning actions, forms, data display, feedback, navigation, overlays, layout, and internationalization; 3 primitive hooks; and 6 shared items, including optional theme resources. The [component index](/docs/components) remains component-focused and is validated against the 62 UI items in the source manifest.
